# Spike 009: private-access

## What This Validates
Given equally capable private learners that retain childhood knowledge, when cue quality and access vary, then matched deference effects and cognitive states are measurable without changing ability. Technical evidence and evolutionary interpretation remain separate.

## Results
**VALIDATED.** Source access changes the deference advantage. Main retained-model N contrast near tau3 is +33.9% default, +40.2% noisy, +85.5% private-sparse and +13.6% when both sources slow. Neutral and d0 controls pass. More independent facts can dilute adult knowledge too.

See [results](../../../v5/results.md) and [verification](../../../v5/verification.md). Scientific claims remain conditional on specified information, memory, query-cost and inheritance assumptions. No conclusion about a distinct historical childhood adaptation follows from software verification.
