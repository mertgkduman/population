# V5 model comparison

| Model | Information retained | Adult correction | What it identifies | Main limitation |
|---|---|---|---|---|
| Private-only, retained d=0 | All privately acquired childhood u=b | Continues on new private cues | Strong individual-learning comparator | Finite evidence scores |
| Retained social learner | Private u plus socially modified b | Continues on new private cues | Current override plus cultural memory | d bundles two mechanisms; factorial needed |
| Frozen adult conviction | Same juvenile acquisitions | No adult private queries | Retention versus ongoing noisy input and sampling cost | Freezing is an imposed architecture |
| Confidence audit | Same juvenile acquisitions | Frequent when uncertain, occasional when confident | Cost-sensitive attention comparator | Specified heuristic, not proved optimal |
| Reset ablation | Childhood scores discarded at maturation | Relearns as adult | Causal role of retention | Deliberately weak ablation, not the main private competitor |
| Oracle confidence gate | Selectively accepts testimony | Continues updating | Privileged source-quality bound | True current reliability and finite-score proxy; not full Bayes |
| Multi-context repertoire | Actual arrays of facts and scores | Update/freeze/audit | Knowledge coverage and intergenerational transmission | Discrete cohorts; no demographic fitness |
| Confidence-qualified tutors | Same repertoire, observable confidence-based source search | Update/freeze/audit | Source selection and information availability | Search across full cohort is cost-free |
| Exact Bayesian benchmark | Correctly calibrated prior and private likelihoods | Optimal updating for a stable binary task | Cost-free value-of-information bound | No cultural demography, change, query cost or correlated cues |

The two-stage distribution model is the main demographic/evolutionary model. Its cognitive states are necessary to avoid treating adult wisdom as an externally supplied number. The multi-context and Bayesian companions deliberately isolate aspects that the demographic closure cannot represent cleanly. Their outcomes are not combined into an arbitrary common fitness score.

Alternatives considered were a full individual-based ecological simulation with combinatorial rules, a richer Bayesian belief distribution over teachers, and a cohort model with fixed maturation age. They would answer different questions and introduce more mechanisms than can be identified in this version. The main `load` factor therefore remains explicitly a rate transformation. The repertoire experiment represents many independent facts, not semantic complexity, normative collaboration or general reasoning.
